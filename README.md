# CodeBlock

**Block-based GameMaker** with visual script editor, play, compile and download.

## Features

- Visual block editor (drag & drop)
- Script maker
- Live play / preview
- Compile
- Download your game

## About

CodeBlock is a tool that lets you create games using visual blocks instead of pure code.  
Perfect for beginners and for rapid prototyping.
